## Project Overview

`github.com/lindb/common` is a Go utility library shared across LinDB (a distributed time-series database) and related libraries. It provides common data models, serialization primitives, and reusable infrastructure packages.

## Commands

```bash
# Run all tests (includes header check + lint + race detector + coverage)
make test

# Run lint only
make lint

# Run a single test
go test ./pkg/logger/... -v -run TestLoggerInit

# Run all tests in a package
go test ./metric/... -v

# Regenerate protobuf and FlatBuffer bindings
make generate          # requires: protoc, flatc (brew install flatbuffers)

# Generate mocks from interfaces
make gomock

# Check/add Apache 2.0 license headers to all files
make header

# Run integration tests (requires 'integration' build tag)
make e2e-test

# Tidy/verify Go modules
make deps
```

## Architecture

The library is layered: protocol definitions at the bottom, domain builders on top, and utility packages on the side.

### Protocol Layer (`proto/`)
- `proto/v1/*.proto` — Protobuf definitions for logs and traces
- `proto/v1/*.fbs` — FlatBuffers definitions for metrics (chosen for zero-copy read performance)
- `proto/gen/v1/` — Generated Go code (do not edit manually; regenerate with `make generate`)
- `proto/generate.sh` — Drives `flatc` and `protoc` code generation

### Data Model Layer (`models/`)
In-memory query result structures consumed by LinDB query engine:
- `ResultSet` — top-level query response containing multiple `Series`
- `Series` — a tagged time-series with field values
- `Metadata` — database/metric metadata
- `Exemplar` — trace exemplar attached to metric fields
- `QueryStats` — query execution performance statistics

### Domain Builders (`metric/`, `log/`)
- `metric/row_builder.go` — `RowBuilder` constructs a FlatBuffer-encoded metric row; uses xxhash to hash sorted tag key-values; pooled via `sync.Pool`
- `metric/checker.go` — `Checker` validates metric rules (name length, tag count limits, field constraints)
- `log/row_builder.go` — Builds protobuf-encoded log rows

### Utility Packages (`pkg/`)

| Package | Key Types / Functions |
|---|---|
| `pkg/logger` | `GetLogger(module)` → zap-based logger; color output in TTY; lumberjack file rotation; configure via `InitLogger` |
| `pkg/encoding` | `JSONMarshal/Unmarshal` (json-iterator); `Copy` for deep-copying via JSON |
| `pkg/fasttime` | `UnixNano()` — fast monotonic timestamp without syscall |
| `pkg/timeutil` | Millisecond/nanosecond conversions, interval parsing |
| `pkg/fileutil` | `ReadFile`, `WriteFile`, `MkDirIfNotExist` |
| `pkg/http` | Gin `AccessLog` and `Recovery` middlewares; `OK`/`Fail` JSON response helpers |
| `pkg/ltoml` | TOML config loader with `LoadConfig`/`SaveConfig` and a `Duration` type |
| `constants` | Package-level constants (e.g., default namespace) |

## Code Conventions

- **License headers** — Every `.go` file must have the Apache 2.0 header. Run `make header` before committing.
- **Import grouping** — stdlib → third-party → `github.com/lindb/common/...` (enforced by `goimports` with local-prefix set).
- **Mocks** — Generated by `mockgen` into `*_mock.go` files alongside the source; never edit manually.
- **Line limit** — 140 characters; function length ≤ 180 lines / 100 statements.
- **No `github.com/pkg/errors`** — Use stdlib `errors` / `fmt.Errorf` instead (enforced by depguard).
- **No `logrus`** — Use `pkg/logger` (zap-based) exclusively.
